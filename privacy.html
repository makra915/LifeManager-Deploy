LifeManager – Privacy Policy

LifeManager is a personal Windows desktop application for task and time planning.

Google data accessed

  • Google Tasks – reading, creating, updating and deleting tasks, used to import new items and to show the current plan on the user's phone.
  • Google Calendar – only calendars created by LifeManager itself, used to export the user's plan.

Storage and sharing

Data is processed and stored only locally on the user's own computer. No data is sent to the developer or to any third party. LifeManager's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
